# Шесть Ветров

Изометрическая ролевая игра про архипелаг на шестиугольной сетке: мир поворачивается на 60°, классы и навыки устроены по образцу старой морской MMO, мир можно сгенерировать или нарисовать в редакторе.

- [Диздок](docs/GDD.md): мир, генератор и редактор, характеристики, классы, навыки, бой, существа, предметы, профессии, корабль, задания, управление, таблицы.
- [Дорожная карта](docs/ROADMAP.md).

Запуск: открыть `index.html` через любой статический сервер. Тесты: `jest sixwinds` из `app/src/games` (ES-модули, `node --experimental-vm-modules`).
